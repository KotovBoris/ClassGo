# Требования «ClassGo» (источник истины для тестов)

Каждое требование пронумеровано (`XX-N`) и имеет ожидаемый результат.
Тесты ссылаются на эти ID. При расхождении кода и документа — расхождение считается
дефектом (либо кода, либо этого документа).

Обозначения: **[HTTP]** — REST ручка, **[BOT]** — поведение чат-бота, **[UI]** — клик/экран
мини-приложения, **[NFR]** — нефункциональное требование.
