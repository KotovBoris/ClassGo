## Ветка final-defense: ответ на отзыв экспертов онлайн-этапа

Эксперты попросили уточнить, как на пилоте проверять покупку билета, и добавить в план пилота
согласование приказа с юристом. Ветка отвечает на первое в продукте, на второе — в презентации
(первая неделя пилота). Стенд https://213.193.198.71 выкачен из `final-defense`.

| Что | Где | Зачем |
|---|---|---|
| Билеты от родителей | `tickets.py`, `/excursions/{id}/tickets`, `bot._on_ticket_upload` | Родитель присылает фото или PDF билета (или чек) в чат бота или в приложении. Учитель видит «прислали X из Y», листает билеты на входе и получает все одним PDF (`build_tickets_pdf`: обложка, билеты по алфавиту, последний лист «для учителя» — кто без билета). |
| Проверка файла | `tickets.normalize` | Фото открывается целиком: поворот по EXIF, белый фон вместо прозрачного, до 2400 px, JPEG без геометки. PDF — 1–10 страниц, без пароля. Иначе понятный отказ. Файлы удаляются через 7 дней после выезда и при отзыве согласия. |
| Ссылки на файлы | `tickets.signed_url` | Подпись привязана к самому файлу (соль — имя файла), ссылка на билет живёт сутки, на PDF класса — 10 минут. |
| Класс без Excel | `joins.py`, `/parent/join-request`, `/join-requests/{id}/decide` | Родитель по ссылке класса вписывает ребёнка, учитель подтверждает (можно поправить ФИО). Если ученик уже есть и у него есть родитель — предупреждение и отдельная кнопка «Это второй родитель»; «Подтвердить все» такие заявки пропускает. Не больше 3 открытых заявок от родителя и 60 на класс. |
| Второй родитель | `/parent/pair`, `bot.notify_parent_added` | По ссылке от первого родителя — заявка, её подтверждает учитель; уже подключённые родители получают сообщение. |
| Бот и группы | `bot._on_message` | В групповых чатах бот ничего не принимает и не отвечает туда. Вложения качаются только по https с публичных адресов, до 3 редиректов и 30 секунд. |
| Демо | `demo.py` | В выезде-примере виртуальные родители «присылают» билеты-образцы. Билет зависит от события: у спектакля — зал, ряд, место; у музея — входной билет на сеанс. На каждом пометка «ОБРАЗЕЦ · демо-данные». |
| Тесты | `tests/test_tickets_joins.py`, `tests/test_review_security.py`, `tests/test_polish.py` | 267 тестов бэкенда; 31 — на файлы билетов, подписи ссылок, заявки и права. |

## Ветка final-polish

Ветка собрана поверх `main` (тег `snapshot-2026-10-23-before-polish` — состояние до правок).

### Как посмотреть

- Стенд: https://213.193.198.71, бот @t158_hakaton_max_bot (сейчас выкачено из `final-defense`).
- В MAX: открыть бота → «Попробовать демо». Вы станете учителем демо-класса 7Б и
  родителем Тимура: виртуальные родители отвечают сами за минуту, двое молчат,
  чтобы можно было нажать «Напомнить».
- Локально: `backend` — `uvicorn app.main:app`, `miniapp` — `npm run dev`;
  вне MAX пользователь задаётся параметром `?user_id=…`.
- Тесты: `cd backend && python -m pytest -q` (267 тестов), сценарий с эмулятором MAX —
  `scripts/e2e_agent.py` (24 проверки), стенд — `scripts/e2e_docker.py`.

### Откат

- Код: `git checkout snapshot-2026-10-23-before-polish` (или выкатить `main`: `~/run.sh`).
- Сервер целиком (код, `.env`, `run.sh`, volume с базой, образы):
  `bash /root/backups/snapshot-20261023/rollback.sh`.

### Бэкенд (`backend/app`)

| Что | Где | Зачем |
|---|---|---|
| Кто делает запрос | `auth.py` | `X-Max-Init-Data` проверяется токеном бота, user_id берётся из подписи, подпись старше суток не принимается. Когда бот включён, работает строгий режим: без подписи — аноним, поддельная подпись — 401. `?user_id` — только локально и в тестах. |
| Права доступа | `main.py` `_can_view_class`, `_class_editor`, `_is_parent_of` | Учитель видит и меняет только свои классы и выезды, родитель — только своего ребёнка. Приказ скачивается по подписанной ссылке на 10 минут. Вебхук — только с секретом, сброс демо — только с `X-Admin-Token`. Бэкенд слушает 127.0.0.1, наружу — только через Caddy по HTTPS. Тесты: `test_security.py`. |
| Часовые пояса | `timeutil.py`, поля `timezone` у класса и выезда | Срок ответа, время в документах и сообщениях — по часам школы (пояс берётся с телефона учителя при создании класса). Тихие часы — по часам родителя (`X-Timezone`). Тесты: `test_timezones.py`. |
| Демо-песочница | `demo.py` | Свой класс 7Б на каждого, виртуальные родители с задержкой, «живое демо» по QR: жюри становится родителями. |
| Подключение родителя | `main.py` `/classes/{id}/invite`, `/join` | Одна ссылка на класс; номер из `requestContact` с проверкой HMAC (`max_validate.verify_phone`). |
| Второй родитель | `/parent/second-invite`, `/parent/pair` | Одноразовая ссылка от первого родителя, живёт сутки. В `final-defense` — через заявку, которую подтверждает учитель. |
| Юридическая модель | `UserProfile.terms_accepted_at`, `/me/accept-terms`, `/parent/revoke` | Соглашение о ПЭП (63-ФЗ ст. 9) и отдельное согласие на ПДн (152-ФЗ ст. 9), отказ — бумага. Без них ответ не принимается: API — 409, бот сначала показывает оба текста (`bot._ask_terms`). |
| Живое демо по QR | `demo.sandbox_invite_code`, `demo.adopt_virtual_child`, `demo.retire_previous_trips` | Ссылка демо-класса постоянная (не меняется после «Начать демо заново»). Гость из зала получает ученика, за которого ещё не ответили; запасных учеников хватает на 200+ человек. Новый выезд в демо-классе закрывает прежний пример без рассылки — у гостя одно приглашение. |
| Файлы в чат MAX | `max_client.MaxClient` | Доверяем и российскому корню (API MAX), и публичным CA (сервер файлов `fu.oneme.ru`); пока MAX обрабатывает файл (`attachment.not.ready`), повторяем отправку. |
| Ответ на согласие | `services.apply_consent`, `/consent` | Отвечает только родитель ребёнка; учитель отмечает лишь бумажный бланк, его MAX ID в подпись не пишется. Запись — условным UPDATE (два одновременных нажатия не перезапишут друг друга), после начала выезда ответ не принимается. |

### Мини-приложение (`miniapp/src`)

Интерфейс на `@maxhub/max-ui` (цвета, шрифт, тёмная тема MAX). Правила для родителей
40–70 лет: текст от 17 px, главная кнопка 56 px, статус словом + значком + цветом.
Необратимые действия — через `Confirm` (`ui.tsx`): шторка, где словами сказано, что произойдёт.
Вне MAX приложение показывает «Откройте ClassGo в MAX» — подставить чужой `user_id` нельзя.

| Экран | Файл | Что важно |
|---|---|---|
| Приветствие | `Welcome.tsx` | Выбор роли и «Попробовать демо». |
| Учитель: главная | `TeacherHome.tsx` | Выезды впереди, прошедшие и отменённые отдельно, классы. |
| Новый выезд | `NewTrip.tsx` | 3 шага: афиша или своё событие → когда/как/помощник → «так увидят родители». |
| Выезд | `TripScreen.tsx` | Сводка ответов, «Напомнить», списки, документы, бумажный бланк, день выезда, отмена. Бланк и «Группа выехала/вернулась» — с подтверждением (сколько родителей получат сообщение, сколько не отмечено). |
| Класс | `ClassScreen.tsx`, `NewClass.tsx` | Ссылка/QR для родителей, список из Excel или вставкой. Телефон учителя обязателен. |
| Родитель | `ParentHome.tsx`, `ParentTrip.tsx`, `Terms.tsx` | Соглашение в 2 шага, ответ одной кнопкой, квитанция, звонок учителю. «Изменить ответ» не стирает прежний; «Отвечать на бумаге» и «Отозвать согласие» — с подтверждением и объяснением последствий. |
| Подключение | `JoinScreen.tsx`, `PairScreen.tsx` | По ссылке класса и по ссылке второго родителя. |

### Что проверить руками перед защитой

1. Демо в MAX с телефона: приглашение в чате, «Да» → квитанция, сводка ответов у учителя.
2. «Прислать документы в чат» — PDF открывается в MAX.
3. QR живого демо со слайда 5 ведёт в демо-класс; второй телефон получает другого ученика.
4. «Изменить ответ» в боте: прежний ответ виден у учителя, пока не выбран новый.
5. Перекличка → «Группа выехала» → шторка с числом родителей → сообщение пришло.
