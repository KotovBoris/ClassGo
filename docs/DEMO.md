# Сценарий демонстрации «ClassGo» (для защиты)

Готовый план показа проекта. Укладывается в 5–7 минут.

## Подготовка (за 2 минуты до защиты)

```bash
cd classgo
cp .env.example .env        # при необходимости впишите MAX_BOT_TOKEN
docker compose up -d --build
# проверка живости
curl -s http://localhost:8080/healthz
# сброс демо, чтобы состояние было чистым
curl -s -X POST http://localhost:8080/api/v1/admin/reset-demo
```

Открыть в браузере: **http://localhost:8080** (телефонный вьюпорт — Ctrl/Cmd+Shift+M).

## Что показывать по шагам

| Шаг | Действие | Что говорим жюри |
|---|---|---|
| 1 | Открыть бота **@t158_hakaton_max_bot** в MAX, нажать «Начать» | «Вход строго через бота MAX; видим приветствие и нативную кнопку мини-приложения» |
| 2 | Показать в боте `/trips` | «Родитель видит статусы по своему ребёнку прямо в чате» |
| 3 | В mini-app: вкладка **«Каталог событий»**, включить «Пушкинская карта» | «Событий много, но нет школьного сценария — берём на себя связку со школой» |
| 4 | «Выбрать событие» → «Создать выезд» | «Весь класс добавлен автоматически, статусы — «ожидает»» |
| 5 | Дашборд **«Сводка ответов»** (🟢/🟡/⚪/🔴) | «Учитель видит готовность класса в одном экране вместо тетради и Excel» |
| 6 | «Напомнить не ответившим» | «Точечные пуши в личку, а не флуд в чат класса» |
| 7 | Открыть экран родителя: в режиме просмотра (вне MAX) выбрать ребёнка **или** `?startapp=1` | «Родитель подтверждает участие одним нажатием» |
| 8 | Нажать «Отпускаю ребёнка» | ответ сохраняется: кто, дата и время |
| 9 | Вернуться в «Сводка ответов» — статус изменился | «Сбор группы вместо 4–7 дней занимает часы» |
| 10 | «Сформировать приказ (DOCX)» + «Скачать PDF» | «Пакет документов для директора — автоматически, за секунды» |

**Ключевые фразы для жюри:**
- «Сервис **не касается денег** — оплата напрямую в кассу музея (снятие риска «поборов»)».
- «Данные каталога — **модельные**, реальная интеграция с PRO.Культура.РФ — следующий шаг».
- «Каталог в демо — подготовленный список по Казани, не живая афиша».

## Если показываем живой MAX

- Бот уже подключён (polling) и **команды зарегистрированы** в MAX.
- Для кнопки «Открыть приложение» нужен публичный HTTPS-адрес mini-app (указать в настройках бота).
- Если токена/сети нет — показать запись экрана мини-приложения (вне MAX всё работает).
