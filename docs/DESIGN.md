# DESIGN.md — дизайн-контракт ClassGo (v2 «Бригадир»)

Формат: Google DESIGN.md. Задача файла — зафиксировать одно направление так, чтобы **все экраны
строились из него**, а не «дорисовывались» по вкусу (иначе возникает AI design-system drift).

**v1 («Ведомость») → v2 («Бригадир»):** v1 осознанно была «цифровым бланком» (бумага, чернила,
штампы, hairline, ~0 радиус). Но независимый разбор (скилл `frontend-design`, Anthropic) показал,
что **broadsheet-вёрстка с hairline-линиями и около-нулевым радиусом — это AI-телл №3**, а «моно
для мелких данных», `·`, `—`, `→` — телл №5. Направление пересобрано от предмета, а не от шаблона.

## 1. Grounding — из чего сделан мир продукта

| Вопрос | Ответ |
|---|---|
| Что это и для кого? | Сервис школьных культурных выездов. Основной пользователь — **классный руководитель**; вторичный — родитель |
| Из чего мир сделан? | Сбор группы перед автобусом: **список класса, согласия, билеты, посадка по местам**, приказ на бланке |
| Самое характерное? | **Рассадка**: кто едет (согласие), у кого билет, кто ещё молчит. Это «Сводка ответов» |
| Что сделал бы конкурент? | Центрированный заголовок, три карточки, фиолетовый акцент, круглые аватары — дефолт |

**Вывод:** это **диспетчерская выезда**, а не маркетинговый лендинг и не «официальный бланк».
Главный объект — состав группы и его готовность.

## 2. Направление v2: «Бригадир»

Тёплый лист для чтения + один акцент **действия** (индиго-синий) = **навигационная метка** «сюда» (как
метка на карте маршрута). Красный зарезервирован за опасностью/отказом — акцент и деструктив
разведены по значению (см. [`COLOR.md`](COLOR.md)). Плотно, функционально, «кабинетное», без декораций.

### Палитра (из мира выезда)

| Роль | Токен | Значение | Откуда |
|---|---|---|---|
| Фон приложения | `--line` | `#E4E1DA` | тёплый бумажный, не cream `#F4F1EA` (SD1) |
| Лист/карточка | `--sheet` | `#FFFDF8` | светлее фона — поверхность читается как слой |
| Утопленная поверхность | `--raised` | `#F6F3EC` | поля, шапка таблицы |
| Чернила | `--ink` | `#1C1A17` | текст |
| Приглушённое | `--ink-2` | `#6A6459` | подписи |
| **Акцент действия (primary)** | `--accent` | `#1D4ED8` | индиго-синий: главное действие/бренд/ссылки — единственный акцент |
| **Акцент при нажатии** | `--accent-ink` | `#1E40AF` | hover/active primary, текст ссылок |
| **Danger / отказ** | `--stop` | `#B3121A` | красный: **только** деструктив/отказ/критическая ошибка |

Статусы («Сводка ответов») — **не декор, а смысл**: `--ok #1F7A4C`, `--wait #8A5A12`, `--idle #6F6A63`,
`--stop #B3121A`. Оттенки подобраны под контраст ≥ 4.5:1 на светлом листе.

Правило: акцент `--accent` — **редко** (главное действие, знак бренда). Работу несут чернила и сетка.
Красный (`--stop`) — **только** опасность/отказ/ошибка/срочность, никогда не «главное действие».

### Типографика

| Роль | Гарнитура | Почему |
|---|---|---|
| Всё | **Golos Text** (400/700, variable) | кириллица, «официально, но современно»; под домен, а не Inter |
| Числа | тот же Golos Text + `font-variant-numeric: tabular-nums` | разряды дат/денег выравниваются **без** отдельного моно-шрифта (моно — телл №5) |

Масштаб: 12 / 13 / 15 / 17 / 20 / 22. Заголовки — **sentence case**, без ALL-CAPS, без «одно слово
в заголовке цветным».

### Сетка и layout

- **Не центрируем.** Заголовки и блоки прижаты влево.
- Радиус поверхностей **12px**, вложенных меток — 8px (не «всё по 2px» — это иерархия, не поза).
- Линии — только там, где кодируют структуру таблицы; **теней нет**.
- Плотность: 8px база, компактные строки таблиц.
- **Hero выезда** — первый экран учителя: название, место, дата/сбор/билет. Не «большая цифра».
- **Готовность списка** — ступенчатая полоса (сегменты по статусам) + счётчики словами
  («Готов: 12»), а не абстрактный процент.

### Signature detail — «Ряды мест»

Единственная яркая деталь: **места в автобусе как места в зрительном зале**. Сетка 4 в ряд,
номер места сквозной, цвет места = статус (готов/ждём билет/нет ответа/отказ), клик — карточка
участника снизу. Это отвечает на вопрос «чей узкий участок» и заменяет безликий список.
Реализация: `.kv-seats`, `.kv-bay`, `.kv-seat-<STATUS>`.

### Движение

Никакого fade-up на блоках и hover-анимаций на карточках. Движение — **только обратная связь**:
отклик кнопки (`:active` `transform: scale(.98)`), появление алерта/инлайн-формы (`kv-enter`,
`opacity`+`transform`), смена статуса места (перекраска). Все анимации — композиторные
(`transform`/`opacity`), ≤ 300 мс, без JS. Длительность/бюджет и обоснование — в
[`MOTION_AND_A11Y.md`](MOTION_AND_A11Y.md). Полное отключение не-essential движения и анимаций —
под `@media (prefers-reduced-motion: reduce)`.

## 3. Доступность (quality floor)

- Контраст текста и статусных цветов ≥ 4.5:1 (текст ≥ 3:1 для крупного).
- Видимый `:focus-visible` (акцентное кольцо) у кнопок, вкладок, полей, места и строки-кнопки.
- **Основной текст — 1rem (16px), масштабируется системной настройкой** (`html { font-size: 100%; }`,
  `-webkit-text-size-adjust: 100%`); тип-шкала в `rem`; вёрстка живёт при +200 % текста и ширине 320px.
- Touch-таргеты: кнопки `min-height: 44px`, вкладка 44px, место — 44×44 (через `min-width/min-height`
  + `aspect-ratio`), чекбокс ПДн 20px. WCAG 2.5.8 (24px) — минимум, 44px — цель для аудитории 50+.
- Перенос вместо обрезки: `overflow-wrap` для длинных слов/ФИО; `nowrap` — только для коротких
  служебных значений (дата/время), осознанно.
- Кликабельная строка журнала — **`<button>`**, а не `tr onClick` (клавиатура/скринридер).
- Все контролы с `aria-label`; место — с подписью «Место N, ФИО, статус»; полоса — `role="img"`.

## 4. Как проверяется

1. `node _tools/avoid-ai-design/scripts/detect.mjs miniapp/src` → **0 P0/P1/P2**.
2. Playwright (`ui-e2e/`, 9 сценариев × 2 вьюпорта = 18) — клики + скриншоты; самокритика по снимкам (`_reviewshots.mjs`).
3. `vitest` (83) — экраны и требования UI-*; `tsc --noEmit` — типы; `vite build` — сборка.
